# 코트 온 산출 (CoatOn Calc) v1
CoatOn v525에서 「산출」 메뉴만 분리한 독립 앱입니다.

포함: 일위대가표 · 도장 시스템 · 견적서 · 실란트 · 메쉬(충진) · 제품 DB/TDS · 사양 DB · 노무비(품셈) 설정 · 백업/복원 · 설정/사용법/안내
제외: 공동주택 견적, LCC, 제품 비교, 면적(도면) 산출, 단지 DB (파일 크기 3.6MB → 약 2.2MB, 단지 DB 2.8MB 제외)

배포: 폴더 전체를 GitHub Pages 등에 올립니다. 같은 도메인의 CoatOn 앱과는 저장 키가 같아 데이터가 공유됩니다(별도 도메인/기기면 백업 파일로 이전).
manual.html 은 원본 설명서 그대로라 제외된 기능 설명이 포함되어 있습니다.
