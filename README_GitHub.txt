[v397] LCC 사양 페이지 개편 + 도장시스템 연결

- 내구성등급(L/M/H/VH) 드롭다운 → 설계 요구 기대 내구연한(7년 이하 / 7~15 / 15~25 / 25년 이상) 자동 표기, 실제 요구는 "소비자 요구 연한"에 입력(추정수명·LCC 기준수명으로 사용). 적용한계는 등급 연동(L=C2, M=C3, H=C4, VH=C5).
- 표면처리(노무비) 원/㎡: 노무단가(원/인·일) ÷ 일 작업량(㎡/인·일) 산식 표기, 두 값 입력 시 자동 계산(직접 입력도 가능).
- 일위대가표: 도장S로 사양을 선택하거나 "견적서 생성"을 누르면 하도/희석제, 중도/희석제, 상도/희석제의 산출 정보와 규격·단위·소요량·단가·금액을 표로 로딩.
- 희석제 소요량은 도장 시스템과 같은 기준(kg 제품은 체적 기준)으로 맞춤.

- 현재 화면을 실제 화면(열린 오버레이·페이지) 기준으로 판별 — 단지 DB 검색 등 다른 경로로 열린 화면에서도 뒤로·홈 버튼이 비활성화되지 않음.
- 홈 버튼: 열려 있는 모든 화면·시트를 닫고 항상 시작 화면(홈)으로 이동. 뒤로가기: 바로 이전에 실행한 메뉴로, 이전 기록이 없으면 홈으로.
- 오버레이를 자체 닫기 버튼으로 닫은 뒤에도 이동 기록이 어긋나지 않도록 자동 보정.
- 하부 고정 메뉴: 이미 열려 있는 화면(제품 DB·단지 DB 등)을 다시 누르면 재로딩 없이 메뉴만 닫음, 메뉴 선택 시 패널을 먼저 닫고 이동해 화면이 멈추지 않음. 시스템 선택 시트 등 남은 팝업도 함께 정리.

[v399] LCC 사양 페이지 정리
- 도장S: 도장 시스템 페이지의 '저장S'(저장된 시스템)와 동일한 화면을 열고, 불러오기를 누르면 LCC 사양에 적용.
- 하·중·상도 입력 카드, 코트 추가, 견적서 생성 버튼 삭제 → 일위대가표 카드만 남김.
- 일위대가표 카드에 '시스템수정' 추가: 도장 시스템 페이지에서 코트·단가를 고치고 시스템 '저장'을 누르면 LCC 사양에 반영되고 LCC로 복귀.
- 시스템 저장 시 제품 단가·희석제 단가·DFT·SVR·로스·희석율도 함께 보관(불러오기 시 복원).
- 명칭 변경: 현재사양→도장사양, 기본사양→범용사양, 추천사양 유지. 카드는 파스텔톤(파랑/살구/민트)으로 구분.

[v400] LCC 자산 탭을 '자산 페이지 단독' 코드로 교체 — 유형(플랜트·공동주택·물류창고·교량·기타) 선택, 자산 목록·추가/삭제, 부식환경 측정, 조건 보정, 보수 시기 판정, 보수 시기 고정바(하단) + 페이지 맨 아래 JSON/CSV 저장. 보수 시기 판정은 도장사양(현재 도막) 기준으로 대시보드와 동일하게 계산합니다.
- 상단 이미지(히어로) 통일: 모든 페이지의 높이를 일위대가표와 같은 250u로 맞추고, 상단 고정(sticky) 방식도 일위대가표와 동일하게 적용 — LCC, 전체 메뉴, 견적서, 도장 면적 산출, 공동주택 견적(단지별), 단지 DB.
- 노무비 설정 시트: 하단 메뉴에 가려지던 '완료' 버튼이 보이도록 시트를 하단 메뉴 위로 올림.
- LCC 자산 > 부식환경 측정: 측정장소(시도→측정소) 선택 추가. 에어코리아 대기환경월보 2026년 4월 측정소별 SO₂ 월평균(ppm)을 mg/㎡·일로 환산(×2096)해 입력. 직접 수정하면 선택은 해제됨. 요구 내구성 표기를 L·M·H·VH + 연한으로 변경.
- 숫자 입력란 선택 시 나타나던 키보드 위 '완료' 버튼 삭제.
