[GitHub Pages로 아이폰에서 사용하기]
1) GitHub 저장소(Paint-Quantity-Calculat)에 이 폴더 안의 파일을 "그대로" 올립니다.
   (index.html, apt-db.json, sw.js, manifest.json, icon-192.png, icon-512.png, icon-180.png, icon-maskable-512.png, .nojekyll)
   ※ PQC 폴더째 올리지 말고 폴더 안의 파일들이 저장소 맨 위(루트)에 오도록 올리세요.
2) Settings > Pages > Branch: main / (root) 저장
3) 아이폰 사파리에서 https://only12you.github.io/Paint-Quantity-Calculat/ 접속
4) 공유 버튼 > 홈 화면에 추가 → 앱처럼 사용
※ TDS(PDF)·엑셀·OCR·이미지 저장은 처음 한 번 인터넷이 필요합니다.
※ 업데이트 후 옛 화면이 보이면 홈 화면 앱을 완전히 종료했다가 다시 실행하세요.

※ 앱 아이콘: 기본은 파란색 PQC V2 아이콘입니다. 초록색을 쓰려면 icons_alt_green 폴더의 icon-*.png 4개를 루트의 같은 이름 파일에 덮어쓰세요(icons_alt_green 폴더 자체는 올리지 않아도 됩니다).
※ 홈 화면 아이콘은 이미 설치한 경우 바뀌지 않으니, 홈 화면 앱을 삭제하고 다시 추가하세요.

[v393] 공동 페이지(APT v23) 단지 기본 정보 칸 깨짐·헤더 높이 어긋남 수정 — 메인 앱 스타일과 겹치던 부분 정리

[v394] 공동 페이지(APT v24) 디자인 교체 — 시안 반영: 헤더(제목 한 줄·검색·공유), 배너, 세대수/동수/준공연도 요약 카드(누르면 수정), 동별 층수·평면도·단면도 탭, 하단 단지 전체/선택 공동 합계 카드. 평면도의 동 배치 개략도는 기존 그대로 유지. 단지 DB 검색은 상단 돋보기. 공동 화면에서는 메인 앱의 페이지 전환 알약을 숨깁니다.

[v395] 공동 페이지(APT v25) — 평면도 동 배치 개략도를 시안처럼 교체(도로·단지 경계선·보행로·수목·나침반·주출입구, 동별 3D 블록과 동 이름표, 선택 동 파란색 강조, 동 수에 따라 자동 배치). 헤더 뒤로가기를 < 로, 요약 카드 항목별 아이콘.

[v396] 단지 DB 관리 추가 — 더보기 > 단지 DB(제품 DB 옆)에서 ‘면적 정보 DB’와 ‘기본정보 DB’를 따로 등록(JSON·CSV·엑셀)·삭제. 검색 시 단지코드로 합쳐서 불러옵니다(타입·전용면적·관리비부과면적=면적 정보, 주소·동수·최고층수·사용승인일=기본정보). 단지 검색 화면에는 작은 ‘DB 관리’ 링크만 둠. 기본정보에만 있는 단지도 검색되며 세대수만 채워집니다. 최고층수는 선택 시 동별 층수에 채워줍니다. 등록한 DB는 이 기기에만 저장됩니다.
※ v396: 단지 정보 채우기 시 기본정보 DB의 사용승인일을 요약 카드 ‘준공연도’ 칸에 표시(예: 2004.05.17). 기본정보가 없는 단지는 비워 둡니다.
※ v396: 단지 DB 화면 개편 — 상단 앱바(뒤로·검색·홈), 둥근 배너, 단지 카드(지도보기·단지코드·세대수/동수/관리비부과면적/최고층수 타일), 기본정보 표, 세대 타입(색 점), 환산 배율 패널, 최고층수 채우기 토글, 채우기 버튼. 목록·DB 관리 화면도 같은 틀로 통일.
