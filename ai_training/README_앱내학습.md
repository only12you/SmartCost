# 앱 안에서 학습하기 (오프라인 · 무료) — v463

PC·구글 코랩 없이, 앱(현장진단)만으로 AI를 학습합니다. 인터넷·서버·유료 서비스가 필요 없고 사진은 기기 밖으로 나가지 않습니다.

## 이전(v462)에는 어떻게 동작했나
- 분석은 **학습 모델이 아니라 색·밝기 규칙**(녹=주황·갈색 색상, 균열=주변보다 어두운 선 등)이었습니다.
- '기준 색 지정'은 모델 학습이 아니라 사진별 기준값 보정이었고, 학습 데이터는 **모으기만** 했습니다(PC에서 따로 학습해야 함).

## v463 학습 방식
1. 정답 만들기 (결과 화면 → 항목)
   - **인식 영역 수정**: 잘못 잡힌 곳을 지우고 놓친 곳을 칠하고 저장 → 가장 가치 있는 정답(강한 정답)
   - **인식 결과가 맞습니다**: 인식이 정확할 때 한 번 눌러 정답으로 확정(약한 정답, 학습 비중 50%)
   - 설정 → 'AI 학습 데이터'의 *학습용 원본 사진 저장*이 켜져 있어야 합니다(기본값 켜짐).
2. 설정 → AI 학습 → **지금 학습하기**
   - 항목(녹·균열·…·주름)마다 작은 신경망(입력 14개 특징 → 은닉 12 → 출력 1)을 학습합니다.
   - 특징: 밝기·색(사진 중앙값 대비 포함)·채도·국소 대비·질감·기울기·방향성·기존 규칙 결과
   - 밝기·대비를 흔든 사본으로 함께 학습해 조명 변화에 강하게 만듭니다.
3. **검증 후 자동 적용**
   - 수정한 현장 중 일부는 학습에서 빼 두었다가, 그 사진으로 모델 vs 규칙 방식을 비교합니다(IoU, 면적비 오차).
   - 모델이 규칙보다 0.02 이상 좋을 때만 '적용 중'이 되며, 항목별로 직접 켜고 끌 수 있습니다.
4. 이후 분석부터 해당 항목은 `규칙 → 학습 모델 보정` 순서로 처리됩니다.

## 필요한 데이터량
- 최소: 항목당 수정 사진 4건 이상 + 확정 포함 전체 8건 이상 (서로 다른 현장 2곳 이상)
- 권장: 항목당 30장 이상, 조명·거리·도막 색·바탕을 다양하게. 많을수록 정확해집니다.
- 새로 추가된 결함요소(은폐불량·흐름·색분리·기포·건조불량·빗물자국·퍼티자국·주름)는 초기 규칙의 정확도가 낮으므로 학습이 특히 중요합니다.

## 다른 기기와 공유
- 설정 → **모델 내보내기/가져오기**로 학습 결과(JSON, 수십 KB)를 옮길 수 있습니다.
- 더 큰 모델(U-Net 등)이 필요하면 기존 `README_학습방법.md`의 PC 학습 경로를 그대로 쓸 수 있습니다(내보내기 형식 동일).

## v469 변경 (학습 운영 방식)
- **검사 이력 초기화는 검사 이력만 삭제**합니다. 학습용 정답 사진·수정 영역과 학습 모델은 유지됩니다. (학습 초기화·학습 데이터 삭제는 설정의 별도 버튼에서 사용자가 직접 결정)
- **자료는 교체·삭제하지 않고 계속 누적**합니다. 학습할 때마다 검증용 학습으로 정확도를 측정한 뒤, 쌓인 자료 전체로 최종 학습합니다.
- 항목별 **정확도 추이**(학습 회차별 IoU)와 **새 정답 추가 시 '다시 학습 권장'** 표시.
- 결과마다 **AI 신뢰도**와 '전문가 확인 권장/생략 가능' 안내. 최근 AI 결과의 전문가 수정률이 낮아질수록 확인 기준(신뢰도 85%→최저 50%)이 자동으로 완화됩니다. (확인 이력 10건 이상부터)
