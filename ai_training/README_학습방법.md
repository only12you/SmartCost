# 현장진단 AI 학습 방법 (CoatCost)

앱의 사진 분석을 "색·밝기 규칙"에서 "학습된 모델"로 발전시키기 위한 순서입니다.
앱은 **데이터를 모으는 역할**, 학습은 **PC(또는 구글 코랩)** 에서 합니다.

## 1단계. 앱에서 데이터 모으기
1. 설정 → AI 학습 데이터 → "분석할 때 학습용 원본 사진도 함께 저장" 켜기
2. 현장 사진 촬영 → (가능하면) **기준 색 지정** → 분석
3. 결과 화면 → 항목 → **인식 영역 수정**으로 잘못 잡힌 곳을 지우고, 놓친 곳을 칠하기
   - 수정하거나 등급을 직접 확정한 기록이 **검수 완료**(가장 가치 있는 정답 데이터)입니다.
4. 설정 → **검수 완료만** 내보내기 → `coat_dataset_날짜_verified.json`

권장 수량: 항목(녹·균열·박리·블리스터·초킹)별 **처음 300~500장**, 안정적으로 쓰려면 2,000장 이상.
다양하게 모으세요: 햇빛/흐림/그늘, 가까이/멀리, 도막 색, 철재/콘크리트, 열화처럼 보이지만 아닌 것(오염·그림자·도막 색 차이).

## 2단계. PC에서 학습용 폴더로 변환
```
pip install pillow numpy
python export_to_masks.py coat_dataset_2026-10-25_verified.json -o dataset --verified-only
```
- `dataset/images/` 사진, `dataset/masks/<항목>/` 결함 마스크, `dataset/regions/` 분석 영역(영역 밖은 학습 제외)
- `dataset/split.json` : **현장 단위**로 train/val/test 분할 (같은 현장 사진이 양쪽에 섞이는 것을 막음)
- `--min-quality 1` 을 주면 "재촬영 권장" 사진을 제외합니다.

## 3단계. 모델 학습 (예시)
- 방식: 분할(segmentation) 모델 + 사전학습 가중치 사용(전이학습). 예: U-Net/DeepLabV3+(segmentation_models_pytorch), YOLOv8-seg
- 입력: 사진, 정답: 항목별 마스크(항목마다 따로 학습하거나 다중 클래스)
- 증강: 밝기·대비·회전·흐림·확대(실제 현장 조건 변화를 흉내)
- 평가 지표: IoU/Dice(항목별), 그리고 **면적 비율(%) 오차** — 전문가 판정과 비교
- 목표 예: 면적비 오차 ±3%p 이내, 등급 일치율 80% 이상 (현장·항목에 따라 조정)

## 4단계. 앱에 넣기
- 학습한 모델을 ONNX 또는 TF.js 형식으로 변환(수 MB~20MB)
- 앱의 분석 함수(`analyze`)를 모델 추론으로 교체하고, 모델 파일을 앱과 함께 배포(오프라인 사용 가능)
- 새 모델이 나오면 검증용(test) 사진으로 기존 규칙 방식과 정확도를 비교한 뒤 교체

## 주의
- 앱 안의 기준 색 보정은 "모델 학습"이 아니라 **사진별 기준값 보정**입니다. 모델이 생기기 전까지 정확도를 올리는 용도입니다.
- 사진·결과는 기기에만 저장됩니다. 내보낸 파일에는 현장명과 사진이 포함되니 외부 공유 시 주의하세요.
