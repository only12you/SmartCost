# CoatCost 오프라인·기기 내 AI 설계 (v463 설계안)

## 목표
- iPhone Safari/PWA와 Android Chrome/PWA에서 현장 사진 분석
- 인터넷 연결 및 유료 AI API 없이 작동
- 사진, 검수 결과, 학습용 데이터는 기기 안에 저장
- 현장 검수 결과를 이용한 기기 내 학습을 단계적으로 구현

## 현재 코드에서 확인된 상태
- 현장진단의 `analyze(...)`는 색상·밝기 등의 규칙 기반 분석입니다.
- 설정의 AI 학습 데이터 메뉴는 원본 사진과 정답 마스크를 저장하고 JSON으로 내보냅니다.
- `ai_training/export_to_masks.py`는 PC용 데이터 변환 도구이며, 실제 학습 루프나 학습된 모델은 포함되어 있지 않습니다.
- 따라서 현 버전은 AI 데이터 수집 기능이지, 학습된 AI가 아닙니다.

## 현실적인 기술 결정
브라우저 앱에서 iOS와 Android 모두 완전한 분할 모델을 처음부터 학습시키는 것은 메모리, 배터리, 열, 브라우저 종료 및 기기별 가속 차이 때문에 안정적으로 보장하기 어렵습니다. 특히 iPhone의 Safari/PWA는 백그라운드 작업과 메모리에 제한이 있습니다.

권장 구현은 두 단계입니다.

### A. 첫 배포: 완전 오프라인 추론
- 가벼운 분할 모델을 별도 학습 환경에서 학습해 모델 파일을 앱에 번들합니다.
- 앱은 로컬 모델만 실행하며 네트워크/API 호출을 하지 않습니다.
- 앱 설치 시 모델 파일도 함께 제공하고 Service Worker의 정적 캐시에 포함합니다.
- 모델이 없거나 실행 오류가 나면 기존 규칙 기반 분석으로 되돌아가고, 화면에 AI 모델 미연결 상태를 표시합니다.

### B. 후속 배포: 기기 내 학습
- 현장 사용자는 예측 결과를 수정하고 `검수 완료`로 확정합니다.
- 기기는 사진·마스크·항목·등급·품질 정보를 IndexedDB에 저장합니다.
- 사용자가 명시적으로 실행할 때만 제한된 소규모 학습을 시작합니다. 화면이 켜져 있고 앱이 전면에 있을 때만 진행하며, 취소·저장·복구 기능을 제공합니다.
- 모바일 학습은 우선 모델 전체를 재학습하지 않고, 작은 분류 헤드 또는 경량 파라미터만 조정하는 방식으로 시험합니다.
- 학습 전/후 검증 점수를 비교하고, 검증 성능이 나빠지면 기존 모델을 유지합니다.
- 학습 중단, 저장공간 부족, 기기 과열 시 안전하게 중지합니다.

## 권장 무료 오픈소스 구성
- 학습 코드/데이터 준비: Python + PyTorch (개발용 PC에서 선택적으로 사용)
- 앱 추론: TensorFlow.js 또는 ONNX Runtime Web 중 기기 호환성 시험 후 하나만 선택
- 로컬 데이터: IndexedDB
- 오프라인 설치: PWA + Service Worker + 앱에 번들된 라이브러리와 모델
- 유료 API, 클라우드 추론, 외부 데이터 전송: 사용하지 않음

참고: 모든 소프트웨어 비용을 0원으로 설계할 수 있지만, 개발·시험에 필요한 시간과 기기 비용까지 0원이 되는 것은 아닙니다. 오픈소스 라이선스와 모델 가중치의 사용 조건은 배포 전에 확인합니다.

## 학습 데이터 품질 기준
- 녹, 박리, 블리스터, 초킹, 균열을 별도 라벨로 관리합니다.
- 정상 도막, 오염, 그림자, 반사 등 음성 예시도 포함합니다.
- 같은 현장 사진이 학습·검증 세트에 동시에 섞이지 않도록 분리합니다.
- 전문가가 검수한 데이터만 학습에 사용합니다.
- 면적비 오차, Dice/IoU, 등급 일치율을 기기 내 학습 전후로 비교합니다.
- 자동 등급은 참고값으로 제시하고, 최종 판단을 사용자가 확인할 수 있게 합니다.

## 개발 완료 조건
1. iPhone과 Android 각각에서 비행기 모드로 앱 실행
2. 앱 재실행 후 모델 및 현장 데이터 유지
3. 사진 추론에 외부 네트워크 요청이 없음을 네트워크 검사로 확인
4. 기기 내 학습을 시작/취소/완료하고 앱을 다시 열어도 상태 복구
5. 학습 전후 검증 지표와 모델 버전 표시
6. 학습 성능이 떨어질 때 이전 모델로 되돌리기

## 아직 구현되지 않은 항목
이 문서는 구현 설계이며, 실제 학습된 모델 파일, 브라우저용 학습 런타임, 기기 내 학습 루프는 아직 포함되어 있지 않습니다. 이 파일만으로 AI가 학습하거나 결함을 자동 인식한다고 간주하면 안 됩니다.
