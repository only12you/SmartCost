처음 시작하기앱 구성 · 이동 방법 · 저장 방식

코트 온은 도료·실란트·메쉬의 소요량과 자재비·노무비를 계산하고, 견적서·LCC(생애주기 비용)·제품 비교 보고서까지 만드는 현장용 앱입니다. 인터넷 없이도 계산과 견적서 작성이 되며, 입력한 데이터는 이 기기의 브라우저에만 저장됩니다.

1. 시작 화면

  1. 앱을 열면 Integrated Coating & Maintenance Cost Estimation System 안내 화면이 나옵니다.
  2. 아래 시작하기 버튼을 누르면 홈으로 들어갑니다.
  3. 처음 한 번은 자료 이용 안내 창이 나오며, 내용을 읽고 확인했습니다를 누릅니다.

2. 하단 고정 메뉴 (모든 화면 공통)

버튼동작
‹ (뒤로)바로 전에 열었던 화면으로 이동합니다. 기록이 없으면 홈으로 갑니다.
홈열려 있는 모든 화면·팝업을 닫고 홈으로 이동합니다.

더보기전체 메뉴 화면을 엽니다. 메뉴 검색과 최근 사용 메뉴가 있습니다.

분류 버튼(산출·분석·DB·관리)을 누르면 위로 서브메뉴가 펼쳐집니다. 이미 열려 있는 화면을 다시 누르면 메뉴만 닫힙니다.

3. 전체 메뉴에서 찾기

  • 상단 메뉴 검색에 이름(예: LCC, 견적, 품셈)을 입력하면 해당 메뉴만 보입니다. 이름이 정확히 일치하면 잠시 뒤 자동으로 이동합니다.
  • 맨 아래 최근 사용 메뉴에서 최근 연 화면 5개로 바로 갑니다.

4. 데이터 저장과 백업

  • 모든 입력(제품 DB, 작업 내용, 저장한 시스템, LCC 자산, 제품 비교 입력 등)은 자동 저장됩니다.
  • 브라우저 데이터를 지우거나 기기를 바꾸면 사라지므로 관리 → 백업·복원 → JSON 백업 저장을 주기적으로 하세요.
  • TDS 원본 PDF는 백업에 포함되지 않습니다.

5. 화면 모드 (주간 · 야간 · 자동)

제품 비교 화면 맨 위 오른쪽의 ☀ 주간 / ☾ 야간 / 자동 버튼으로 바꿉니다. 한 번 고르면 앱 전체와 이 설명서에 적용됩니다. 자동은 기기의 다크 모드 설정을 따릅니다.

💡 PDF·OCR·엑셀 변환 도구를 처음 불러올 때만 인터넷이 필요합니다. 한 번 불러온 뒤에는 오프라인에서도 동작합니다.

홈 화면

홈에는 앱 이름(코트 온)과 최근 작업 내역이 표시됩니다. 일위대가표·도장 시스템·실란트·메쉬 등에서 저장한 작업이 최근 순서로 쌓이고, 항목을 눌러 이어서 작업할 수 있습니다.

  • 작업이 없으면 “아직 작업 내역이 없습니다”라고 표시됩니다.
  • 하단의 소요량 공식 · 경고 · 용어 매칭표를 누르면 계산 공식과 용어 설명이 열립니다.
  • 저장된 코트 데이터가 손상되면 그 코트만 초기화하고 나머지는 그대로 보여 줍니다.

산출

일위대가표제품별 소요량 · 단가 · 금액 계산

제품 하나하나(코트)의 소요량과 금액을 계산하는 기본 화면입니다. 산출 → 일위대가표로 엽니다.

화면 구성

영역설명
기본면적맨 위 ㎡ 입력. 코트마다 면적을 따로 넣으면 그 값이 우선합니다. 우측의 도면 버튼은 도장 면적 산출 화면을 엽니다.
도장 시스템 / 시스템도 선택1st · 도장 등 코트 구분 표시. 시스템도 선택은 도장 시스템에서 저장한 시스템을 불러옵니다. + 생성은 DB에 없는 제품을 직접 입력합니다.
소요량 및 조건면적(㎡) · DFT(㎛) · SVR(%) · Loss(%) · 희석율(%) · 제품단가(원/1말) · 희석제 단가(원)
이론/실제 소요량입력하면 자동 계산됩니다. 값이 필요한 칸은 연한 빨간 테두리로 표시됩니다.
제품소개선택한 제품의 설명·규격. 첨부(TDS) · 삭제 · 제품 수정 버튼이 있습니다.
노무비 산출 기준품셈(인/㎡) 또는 생산성(팀 ㎡/일) 중 하나로 입력. 도장공·보통인부 인/㎡.
부자재 소요량내화 메쉬 · 실란트·충진재 체크 시 일위대가표 행으로 합산됩니다.
하단 버튼Coat 추가 · Coat 삭제 · 공유 · 전체 초기화

사용 순서

  1. 기본면적을 입력합니다.
  2. 제품명을 입력해 제품 DB에서 선택하면 DFT · SVR · Loss · 희석율이 자동으로 채워집니다. DB에 없으면 + 생성으로 DFT·SVR을 직접 입력합니다.
  3. 제품단가는 혼합규격 1말 기준 금액, 희석제 단가도 입력합니다.
  4. 결과에서 이론·실제 소요량, 캔(말) 수, ㎡당 단가, 총 금액을 확인합니다.
  5. 코트를 더하려면 Coat 추가(하도·중도·상도 순서로 쌓기).
  6. 세부 내역·출력의 견적서 생성으로 견적서를 만듭니다.

계산식

  • 이론 소요량(L/㎡) = DFT[㎛] ÷ (SVR[%] × 10)
  • 실제 소요량(L/㎡) = 이론 소요량 ÷ (1 − Loss[%] ÷ 100)
  • kg 단위 제품은 비중을 곱해 kg/㎡로 환산, 캔 수량은 올림, 금액은 십원 미만 절사(VAT 별도)
⚠ 계산 결과는 참고용이며 계약·정산의 근거가 아닙니다. 제품 적용 전 제조사 최신 TDS·MSDS를 확인하세요.
도장 시스템하도 · 중도 · 상도 시스템 구성

하도·중도·상도 등 여러 제품을 시스템 하나로 묶어 계산합니다. 산출 → 도장시스템.

  1. 맨 위 면적(㎡)을 입력합니다(화면 위에 고정).
  2. 시스템 카드의 우측 버튼으로 구성합니다.
  3. 제품 줄을 눌러 펼치면 단계 변경 · ▲▼ 순서 · 삭제와 DFT·SVR·Loss·희석율·면적·단가를 입력합니다.
  4. 소요량·금액은 입력 즉시 자동 계산됩니다(계산하기 버튼 없음).
  5. 하단 공유하기로 결과를 공유합니다.

시스템 구성 버튼 4개

버튼기능
사용자사양제품을 직접 골라 시스템을 구성합니다.
DB 열기사양 DB에 저장된 사양을 불러옵니다. 여러 개를 한 번에 불러올 수 있습니다.
사양수정시스템 수정 시트: 코트 칩(하도·하도실러·중도·중도실러·상도)을 고르고 제품명·코드를 입력하면 제품 DB 목록이 아래에 떠서 선택 시 제품명·DFT가 자동 입력됩니다.
사양첨부제조사 사양서(PDF·이미지 OCR)를 읽어 시스템에 바로 적용합니다.
  • 시스템 카드의 저장 / 삭제 / 제품+으로 시스템을 관리하고, ⌄로 접고 펼칩니다.
  • 화면 맨 아래 마지막 제품 삭제 · 전체 초기화가 있습니다.
  • 사양 DB에서 불러온 제품 이름이 제품 DB와 조금 달라도(공백·괄호·제조사명) 자동 연결되어 소개·규격이 표시됩니다.
  • 노무비 산출 기준은 시스템 카드 맨 아래에 시스템 전체 1건으로 입력합니다.
견적서정보 입력 → 미리보기 → 공유
  1. 산출 → 견적서 또는 계산 화면의 견적서 생성으로 엽니다.
  2. 공급자 정보(업체명·대표자·담당자·연락처·주소)를 입력합니다. 체크하면 다음에도 기억합니다.
  3. 견적 정보: 견적일자·견적번호·현장명/공사명·수신·유효기간·결제조건. 견적번호는 발송할 때 확정되며(CC-YYMM-0001 형식) 수정해 다시 보내면 VER 2, VER 3로 구분됩니다.
  4. 도장 품목에는 일위대가표·도장 시스템 계산 결과가 자동 반영됩니다. 제품 사양 표에서 희석제(신나)는 도료와 별도 줄(└ 희석제명)로 표시되어 소요량·㎡당 금액·산출 L가 따로 나옵니다. 품목+ · 도장S · 일위대가표 버튼으로 항목을 추가·가져옵니다. 수량·단가는 직접 고칠 수 있습니다.
  5. 공급가액 · 부가세(10%) · 총 견적금액이 자동 계산됩니다. 비고를 적습니다.
  6. 저장 · 미리보기 · 견적서 생성(이미지/텍스트 공유) · 초기화.
  • 상단 발송 내역에서 이전에 보낸 견적서를 확인합니다.
  • 노무비를 켜 두면 시스템(또는 일위대가표 전체)마다 도장공·보통인부·공구손료 줄이 1세트 들어갑니다.
실란트 소요량줄눈 단면 · 길이 · 포장 수

입력 순서 (화면의 1~4 번호)

  1. 제품 정보: 제품명, 비중(kg/L), 포장 규격(mL·L·kg). 첨부로 데이터시트를 올리면 값이 자동으로 채워집니다.
  2. 단면 프로파일 선택: 직사각형(W×D) · 삼각 코너(½×a²) · 원형 비드(π×r²) · 임의 단면(A mm²) · 면 충진(t×면적).
  3. 충진 부위 입력: 부위 이름을 쓰고 + 추가 → 폭·깊이·연장(길이)을 입력 후 계산하기.
  4. 단면 투시도에서 단면 모양과 배율을 확인합니다. 줄눈은 폭에 맞는 권장 깊이를 안내합니다.

계산 결과

  • 순수 충진량(L) → 로스 포함 소요량(로스율 기본 10%) → 필요 포장 수량(올림) → 예상 재료비 · 총 금액(포장 단가 입력)
  • 계산식 보기: 줄눈 폭×깊이×길이 = mL, 소요량 = 순수 충진량 × (1+로스율), 포장 수량 = 소요량 ÷ 포장 용량(올림), kg 포장은 비중으로 L 환산
💡 “계산하기” 또는 “저장”을 누르면 하단 최근 작업 현황에 쌓이고 일위대가표 부자재에 합산할 수 있습니다.
메쉬 소요량면적 · 롤 수 · 재료비
  1. 메쉬 정보: 메쉬 명칭, 규격, 중량(g/㎡), 롤 폭(m), 롤 길이(m). 롤 면적이 자동 표시됩니다. 첨부로 데이터시트를 읽습니다.
  2. 도포 면적 및 선택사항: 형강 기준은 H형강 규격을 목록에서 고르거나 직접 입력(H·B·tw·tf), 부재 길이(m)·수량(개). 일반·수기는 면적을 직접 넣습니다. + 부재 추가로 여러 부재를 더합니다.
  3. 메쉬 적용 부위: 도형(A~E) 또는 목록을 눌러 선택합니다 — A 플랜지 끝단, B 웨브-플랜지 접합부, C 플랜지 외면, D 플랜지 내면, E 웨브 양면. 전체 / 해제 버튼 제공.
  4. 세부 조건: 플랜지 내·외면 연장, 도막 두께, 겹침 길이, 접합부(B) 띠 폭, 동일 구조 반복(세트), 로스율, 단가 기준(㎡ 단위 / 롤 단위).
  5. 계산 결과: 필요 메쉬 면적 → 로스 포함 소요량 → 필요 롤 수량 → 예상 재료비. 저장 · 초기화.
  • 띠 폭 A = 내면 연장 + 플랜지 두께(tf) + 외면 연장 + 도막 두께
  • 면적 = Σ(길이 × 띠 폭), 소요량 = 면적 × (1+로스율), 롤 수 = Σ(길이 ÷ 롤 폭 줄 수) ÷ 롤 길이(올림)
에폭시 내화 제품(예: FIREMASK 3500)을 일위대가표에서 선택하면 메쉬가 자동으로 포함됩니다.

도장 분석

공동주택 견적단지별 면적 산출 → 공종별 분석
  1. 단지 정보: 세대수 · 동수 · 준공연도가 요약 카드로 표시됩니다(누르면 수정). 상단 돋보기로 단지 DB에서 검색해 채우기(동별 층수 자동 입력).
  2. 동별 층수 / 평면도 / 단면도 탭: 동명·지상·지하 층수를 입력하고 동 추가. 평면도는 동 배치 개략도, 단면도는 층 구성을 보여 줍니다.
  3. 세대 타입: 공급면적(㎡)과 세대수를 입력, 세대 타입 추가.
  4. 기본 공사 항목(외벽 도장 · 내벽 도장 · 옥상 우레탄 방수)과 추가 공사 항목(지하주차장 에폭시 · 보차도 포장 · 아스팔트 싱글 · CCTV 교체 · 주차 차단기 · 교통안전시설) 카드에서 공종을 선택해 시공 조건을 입력합니다.
  5. 산정 기준 · 검증: 원가 제비율(2026), 노임단가 보정(2026.1), 확인 필요 항목 표시.
  6. 견적 저장·불러오기, 하단 단지 전체 / 선택 공동 합계, 견적서·내역서 출력, CSV 저장.
  • 면적 적용 순서: ① 직접 입력 > ② 동별·구역 산출 > ③ 세대 정보 추정
  • 공사 원가계산서에는 간접노무비·보험료·안전관리비·일반관리비·이윤·부가세가 반영됩니다.
  • 단가(재료·노무·경비)는 기본값이며 항목별로 수정할 수 있습니다.
  • 입력값은 JSON 백업에 포함됩니다.
LCC 생애주기 비용도장 상태 진단 · 비용 예측

도장이 지금 어떤 상태인지, 언제 다시 칠해야 하는지, 어떤 사양이 평가기간 동안 총비용이 가장 적은지를 계산합니다. 화면은 대시보드와 5단계로 이어지며, 앞 단계 입력이 뒤 단계 계산에 그대로 이어집니다.

대시보드

  • KPI: 총 생애주기 비용, 예상 수명, 초기 공사비, LCC(추천), CO₂ 절감량(도료 소요량×1.4kg/L×3.0kgCO₂e/kg 가정치)
  • 비용 구성 도넛(초기 도료비·초기 노무/바탕비·재도장 도료비·재도장 노무비·물가 상승분)
  • 비용 추이 그래프: 기간 5·10·20·30·40·50년 선택, 현재 사양 vs 추천 사양 누적
  • 흐름 안내 5단계 카드(자산 등록→진단 평가→사양 설정→비용 분석→보고서 생성)와 추천 사양 바(상세보기)
  • 상단 선택 상자로 전체 프로젝트 / 자산 하나를 고릅니다. 데이터가 없을 때는 예시가 표시됩니다.

1 환경개요

  • 자산: 유형(플랜트·공동주택·물류창고·교량·기타), 자산(구역)명, 면적(㎡), 마지막 도장 후 경과 년, 요구 내구성(L·M·H·VH + 연한). + 추가로 여러 자산.
  • 환경 측정(ISO 12944-2): 구역별 온도·습도·염화물·SO₂·결로·시편 측정. 측정장소(시도→측정소)를 고르면 SO₂ 월평균이 채워집니다. 시편/환경인자/대표환경 3방법으로 판정해 가장 가혹한 등급(C1~CX)을 적용하고 ISO 9223 등급을 표시합니다. 세부 구역은 면적 비중으로 가중 평균합니다.
  • 조건 보정: 화학물질 노출 · 고온 결로 · 바탕 상태 · 시공 품질 · 유지관리를 고르면 수명계수로 곱해집니다. 운영·안전 영향 4항목은 보수 우선순위에 반영됩니다.
  • 결과: 보수 시기 판정 — 잔여 수명 = 예상 수명 − 경과 년. 0년 이하 즉시 · 2년 이하 1~2년 내 · 5년 이하 3~5년 내 · 초과 정상.
  • 하단에서 JSON·CSV로 저장합니다.

2 도막 결함 (현장진단)

  1. 도장 대상(전체·일반·기와지붕·세대문/방화문·내화도료)을 고릅니다.
  2. 사진을 촬영하거나 올립니다. 사진 품질(선명도·밝기·반사·그림자)을 검사해 줍니다.
  3. 사진에 보이는 결함을 고릅니다(녹·균열·박리·블리스터·쵸킹 외 은폐불량·흐름·색분리·기포·건조불량·빗물자국·퍼티자국·주름 등 13종). 기준 색을 찍어 정상 도막/열화 부위를 보정할 수 있습니다.
  4. 분석을 시작하면 인식 영역이 청록색으로 표시되며 원본/분석 결과를 전환하고 칠하기·지우기로 영역을 고칠 수 있습니다.
  5. 결과의 항목별 등급·상태 점수가 자산의 Zone 등급(R 3개월 내 · O 6개월 내 · Y 1년 내 · G 3년 내 재평가)과 현재 사양의 수명 보정계수로 넘어갑니다. 보정 체크를 끄면 보정 없이 계산합니다.
  • 수정·확정한 사진은 기기 안에서 학습 데이터로 저장할 수 있습니다(설정 → AI 학습). 모델 내보내기/가져오기 지원.

3 ISO 사양추천

  • 도장사양(현재) · 범용사양(일반) · 추천사양(환경·자산 유형에 맞춰 내장 사양 중 비용이 낮은 것을 자동 추천, “환경 맞춤 자동 추천” 버튼으로 재추천)
  • 입력: 사양명(직접 입력 또는 도장S로 도장 시스템에 저장한 시스템 불러오기), 내구성 등급(L·M·H·VH)과 소비자 요구 연한, 표면처리 노무비(원/㎡ = 노무단가 ÷ 일 작업량), 코트별 제품·DFT·고형분·로스·희석율·캔 가격·포장
  • 소요량 = DFT ÷ (10 × 고형분) ÷ (1 − 로스), 초기비용 = 재료비 + 표면처리 노무비, 추정수명 = 기준수명 × 환경·조건계수
  • 환경 등급이 적용 한계(L→C2, M→C3, H→C4, VH→C5)를 넘으면 한 단계마다 ×0.75 감점
  • 자산 요약·현재 사양·대안 사진은 카메라/갤러리에서 직접 첨부·삭제(자산별 저장)
  • 시스템수정: 도장 시스템에서 코트·단가를 고쳐 저장하면 이 사양에 반영되고 LCC로 돌아옵니다.

4 비용분석

  • 입력: 평가기간(년), 보수 인상률(%), 대상 설비 — LCC 전체 공통 조건입니다.
  • 계산: 처음 시공비 + 보수주기마다 재도장비용(초기비용 × 면적 × (1+인상률×횟수))을 평가기간까지 누적. 할인율(현재가치)은 적용하지 않습니다.
  • 결과: 판정 배너·KPI 3종, 대안별 한눈 비교표(최저 LCC·최저 비용 표시, 요구 내구성 미달 경고), 누적 보수비 계단 그래프, 현장 설명 포인트. 상세 비교표·수명/비용 그래프는 하단 접이식.

5 보수계획 (최종 보고서)

  • 개요 · 상태진단 · 잔존수명·비용 · 제품선택(최적안) · 효과 · 결론/제안 순서의 보고서
  • 최종 보고서 다운로드(PDF), HTML 저장, Word 저장, 추천사양 → 일위대가표 전송
  • 분석 조건(평가기간·인상률)·대상 선택·자산별 요약·규격 가정은 하단 접이식
  • 보고서 ID는 저장할 때마다 일련번호가 올라갑니다.
⚠ 수명계수와 등급 구간은 선별용 가정값이고, 내장 사양의 단가·노무비·수명은 예시값입니다. 현장 데이터와 실제 견적으로 바꿔 사용하세요. 면적은 자산 탭에 직접 입력합니다(도장 면적 산출·공동주택 견적과 자동 연결되지 않음).
도장 면적 산출부위별 치수로 면적 · 소요량 계산
  1. 상단 유형 탭을 고릅니다: 아파트 · 주택 · 옥상 · 주차장 · 철재 · 차량 · 플랜트 · 기타(한 줄에 보이지 않는 탭은 ··· 버튼).
  2. 01 부위 정보 입력: 부위 탭(외벽·내벽·천장 등)을 고르고 현장·구역 이름(선택), 가로·높이·수량·공제(창·문)를 입력합니다. 철재 유형은 형강 종류(H·I·각·원형강)를 고릅니다. 부위는 ＋ 부위 추가로 늘리고 삭제로 지웁니다.
  3. 02 도장면 정보: 한 면 / 양면 선택.
  4. 03 도장 조건: 도막 두께(DFT µm), 도료 사용량(kg/㎡), 비중(kg/L), 도료 단가(원/L)를 입력합니다. TIP 안내가 함께 표시됩니다.
  5. 오른쪽 최종 산출 결과에서 도장 면적 · 도료 소요량(L) · 무게(kg) · 도장 비용을 확인합니다(스크롤해도 상단에 고정).
  6. 기본면적에 적용(이 유형) 또는 전체 합계로 적용을 누르면 일위대가표 기본면적으로 들어갑니다.

계산식

  • 벽면 = (가로 × 높이 × 수량 − 공제) × 도장 면 수
  • 바닥·천장 = 가로 × 세로 × 수량 − 공제
  • 경사 지붕 = 밑변 × 길이 × √(1+(경사/10)²)
  • 파라펫 = 길이 × (높이 × 면 수 + 상단 폭)
  • 기둥 = 둘레 × 높이 × 수량, 강관 = π × 외경 × 길이 × 수량 × 면 수, H형강 = (4B + 2H − 2tw) × 길이 × 수량
  • 탱크 = π × 지름 × 높이 (+ 지붕·바닥) × 수량, 차량(근사) = 2(LW+LH+WH) × 외판 계수(0.3) × 대수
  • 소요량(kg) = 도장면적 × 도료 사용량 ÷ 비중, 비용 = 소요량(L) × 단가
도면은 개략도이며 면적은 입력한 치수 기준입니다. 곡면이 많은 대상은 근사값이므로 실측 면적이 있으면 “직접 면적” 부위를 쓰세요.
제품 비교기존 제품 vs 추천 제품 분석

두 제품(최대 기존 + 비교 A~D)을 같은 면적·손실률·도막 조건에서 비교해 어느 쪽이 유리한지 보여 주고 A4 보고서까지 만듭니다. 제조사명은 어디에도 표시하지 않습니다. 화면 위쪽 ☀ 주간 / ☾ 야간 / 자동 버튼(한 줄)으로 화면 모드를 바꿉니다.

제품 비교 탭 사용법

  1. 비교 조건 카드(제목을 누르면 접힘): 도장 면적(㎡) · 손실률(%) · 동일 도막 두께(㎛). 도막을 비우면 각 제품의 데이터시트 값을 씁니다.
  2. 기존 제품(파랑, 현재 사용)과 추천 제품(주황) 카드가 VS로 나란히 표시됩니다. 각 카드의 첨부(또는 변경)를 눌러 데이터시트(PDF·엑셀·워드·PPT·CSV·사진)를 올리면 SVR·도막·성능·인증이 자동 추출됩니다. 제품 DB가 연결된 경우 DB 버튼으로 DB 제품을 선택할 수도 있습니다.
  3. 캔 용량(L)과 권장 단가(원, 캔당)는 직접 입력합니다. 입력하면 ㎡당 자재비·실제 도포량·기존 대비 변화율(▲ 좋아짐 / ▼ 나빠짐)이 바로 갱신됩니다.
  4. 카드 아래 추출값 확인·수정을 눌러 자동 추출 값(제품명·특징·용도·성분·성능·SVR·도막·건조시간·VOC·내열·보수주기·인증 등)을 확인하고 틀린 곳을 고칩니다. 추출 표시는 자동 입력 항목입니다. 실적 파일 첨부 · 비우기도 여기 있습니다.
  5. 후보를 더 비교하려면 ＋ 비교 제품 추가(최대 D까지). 추가된 제품은 “다른 비교 제품”에 카드로 나오며 추천 제품으로 선택을 누르면 주황 카드로 올라옵니다. ✕로 삭제합니다.
  6. 비교 분석 결과 4칸을 확인하고 상세 분석 보기로 비교분석 탭으로 이동, 하단 보고서 생성하기로 보고서 탭으로 이동합니다.

칸계산

핵심 계산식

  • 이론 도포율(㎡/L) = SVR × 10 ÷ DFT
  • 실제 도포율 = 이론 × (1 − 손실률)
  • ㎡당 자재비 = (캔당 단가 ÷ 캔 용량) ÷ 실제 도포율
  • 총 소요량 = 면적 ÷ 실제 도포율, 캔 수는 올림
  • LCC = 보수 시점마다 (㎡당 자재비 + 시공비) × 면적 (물가상승 반영) 합계
💡 SVR이 인식되지 않으면 결과가 나오지 않습니다. 추출값 확인에서 SVR(고형분)을 직접 입력하세요. 성능 시험 수치는 시험 규격이 같을 때만 ★ 비교하고, 다르면 “시험 조건 상이”로 표시됩니다.
⚠ 분석 결과는 데이터시트 값과 입력한 단가·조건에 따른 예상치이며 현장 조건에 따라 달라질 수 있습니다.

  • 정렬: 추천순 · 이름순 · TDS 있음순. 검색창은 제품명·제조사·설명 검색이며 오른쪽 버튼으로 검색·필터를 한 번에 초기화합니다.

노무비 설정 시트

  • 노무비 계산 사용: 끄면 도장 시스템·일위대가표·견적서에서 노무비 항목이 숨겨집니다.
  • 도장공 · 보통인부 노임단가(기본: 2026 상반기 시중노임단가, 원/인), 할증(고소·소규모·야간 등, %), 공구손료(노무비 대비 %)
  • 계약 기준 시점의 단가로 직접 수정하세요. 기본값 복원 · 완료 버튼.

노무비 계산 방식

노무비 = 노무량(인/㎡) × 면적 × 노임단가(원/인) (1인 = 한 사람이 하루 일한 양)

  • 방식 ① 품셈: 표준품셈의 ㎡당 인 수를 그대로 입력. 예) 도장공 0.05, 보통인부 0.02 인/㎡ → 100㎡면 5인·2인
  • 방식 ② 생산성: 팀이 하루에 칠하는 면적(㎡/일)과 팀 인원(명)을 입력. 예) 도장공 2명+인부 1명이 80㎡/일 → 0.025 · 0.0125 인/㎡, 100㎡ 시공 시 작업일수 1.25일
  • 값을 비우면 노무비는 계산하지 않습니다. 결과에 공수·금액·재료비+노무비가 표시되고 견적서에 한 세트로 들어갑니다.

도장 품셈 · 노무비 산출 (페이지)

  • 적용 품셈 항목(출처·검증 상태), 품셈 자료 출처, 공식 품셈↔현장 실적 비교·검증, 품셈 기준 관리(항목 추가·수정·삭제).
  • 일치 항목은 제품 DB에서 고르면 자동 연결(제품 전용 복사)됩니다. 제품 데이터와 품셈 데이터는 분리 저장되며 JSON 백업에 포함됩니다.
⚠ 품셈 계수는 앱에 내장하지 않았습니다. 최신 표준품셈과 계약 조건에 맞는 값을 직접 입력하세요.
